# MyPatientHUB 🏥

### Smart Healthcare, Made Simple.

MyPatientHUB is a modern healthcare platform designed to connect patients with doctors, clinics, pharmacies, appointments, and smart health services — all in one place.

## ✨ Features

- 👨‍⚕️ Find Doctors
- 🏥 Find Clinics
- 💊 Find Pharmacies
- 📅 Manage Appointments
- 💬 Chat
- 🛒 Smart Marketplace
- 👨‍👩‍👧 Manage Dependents
- ❤️ Health Index

## 🛠️ Technologies

- HTML
- CSS
- JavaScript

## 🎯 Goal

To make healthcare services easier, smarter, and more accessible for everyone.
